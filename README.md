# Brightside — Simple Website

A clean, responsive landing page starter built with plain HTML, CSS, and JavaScript.

## Features
- Responsive layout for mobile, tablet, and desktop screens
- Mobile navigation menu with accessible state handling
- Smooth in-page navigation and reduced-motion support
- Feature cards, about section, contact call-to-action, and dynamic footer year
- No third-party libraries or build tools

## Project files
- `index.html` — accessible page structure and content
- `style.css` — theme tokens, layout, responsive styles, and motion preferences
- `script.js` — mobile navigation toggle and current footer year

## Run locally
No installation is required. Open `index.html` in a modern browser.

Or start a simple local HTTP server from this folder:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Customize
1. Edit page text and sections in `index.html`.
2. Update the color variables at the top of `style.css`.
3. Replace `hello@example.com` with your preferred contact email.
4. Add new sections or connect a backend contact form as needed.

## Technologies
HTML5, CSS3, and vanilla JavaScript.

There are no external dependencies.
